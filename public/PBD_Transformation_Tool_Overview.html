1. Executive Summary & Core Objectives

The PBD Transformation Tool (PurpleOS Business Operating System) is an all-in-one digital agency operating system specifically engineered for Purplebot Digital. It unifies distributed team management, video production workflows, studio resource allocation, retainer client CRM, financial ledger management, and automated client proofing into a single platform.

3. Module & Feature Specifications

🌅 Executive Morning Briefing & Live Roster

  • Real-time Status Tracking: Aggregates live counts for In Studio, On Shoot, On Leave, and Offline personnel.
  • Automated Telegram Briefings: Pushes daily 9:00 AM summaries to crew Telegram channels.
  • Pending Action Alerts: Highlights pending employment agreements, unapproved expense claims, and urgent tasks.

📋 Task & Production Management Engine

  • Hierarchy Scale: Multi-tiered structure (Spaces → Folders → Lists → Tasks → Subtasks).
  • Custom Task Attributes: Assignees, priority levels, due dates, task labels, custom fields, and task dependencies.
  • Task Templates & Time Logging: Pre-configured workflows for shoot prep, edit revisions, and social post creation.

👥 HR Roster & Designation Directory

  • Employee Master Table: Complete records for staff members including designation, role, email, mobile, department, and pay model.
  • Leave Management: Automated balance computation, submission of leave requests via Telegram, and manager approvals.
  • Security & PIN Access: Phone number verification coupled with 4-digit PIN authentication hashed via JWT.

💰 Finance, Invoices & Expense Approvals

  • Invoice Ledger: Tracks Paid, Draft, and Pending client invoices with automated total calculations.
  • Reimbursements: Crew members upload receipt clips via Telegram or Manager Portal for rapid disbursal sign-off.

🎬 Review Room (Asset Proofing)

  • Client Proofing Interface: Allows client stakeholders to review video cuts, branding collateral, and social graphics.
  • Feedback Loop: Frame-accurate feedback markers, status toggles (Approved / Revision Requested), and automatic notification triggers.

4. System Architecture & Tech Stack

Front-End : Vanilla ES Modules + CSS Token System (tokens.css v3.0) + Mobile Glassmorphism Back-End : Node.js Express API Engine + TTL Caching Middleware + Global Error Handler Database : Supabase PostgreSQL (18+ Tables, Row-Level Security, B-Tree Indexes) Bots Bridge: Node-Telegram-Bot-API Webhook Router (Dual Bot Handlers) Hosting : Vercel Serverless Platform (Edge Static Assets Caching)

5. Quick Team Testing Instructions

  1. Visit the Auth Portal at https://gro10x-ai.vercel.app/auth.
  2. Enter your registered phone number. If logging in for the first time, open Telegram and send /start to @purplemanosbot to generate your 4-digit access PIN.
  3. Log into the Manager Hub (/manager) and test creating a task, reviewing employee profiles, and checking invoice totals.
  4. Open the Workspace App (/app) to verify the Morning Briefing live team counts.
