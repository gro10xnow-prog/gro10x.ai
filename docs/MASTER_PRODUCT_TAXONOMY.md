## 1. The Canonical 7-Tier Hierarchy Formula

Every commercial, technical, and operational asset inside Gro10x strictly conforms to the following 7-tier data model:

$$\mathbf{Company\ (Gro10x) \longrightarrow Engine\ (1\text{--}5) \longrightarrow Vertical \longrightarrow Brand\ (Platform) \longrightarrow Category \longrightarrow Product\ (Agent) \longrightarrow SKU}$$

```
Level 1: COMPANY       Gro10x (Parent Holding & Infrastructure Entity)
Level 2: ENGINE        1 of 5 Fundamental Growth Engines ($100k ARR Model)
Level 3: VERTICAL      Standardized Domain / Market Sector
Level 4: BRAND         Platform Hub, Practice, Operating System, or Media Network
Level 5: CATEGORY      Standardized grouping of products/deliverables
Level 6: PRODUCT       Master listing, autonomous AI agent, service, or OS edition
Level 7: SKU           Stock Keeping Unit with Channel, Pricing & Interval metadata
```

## 4. Canonical SKU Syntax & Rulebook

Every SKU adheres to the deterministic syntax:

$$\mathbf{GRO-E[1\text{--}5]-[VERTICAL]-[BRAND]-[PRODUCT\ CODE]-[CHANNEL]}$$

### Token Definitions:
* `GRO`: Master company prefix (Gro10x).
* `E[1-5]`: Engine identifier (`E1`, `E2`, `E3`, `E4`, `E5`).
* `[VERTICAL]`: 3-letter vertical code (`CAR`, `FIN`, `SME`, `ENT`, `DIG`, `FAS`, `SYS`, `CNT`, `OWN`, `MHL`, etc.).
* `[BRAND]`: 3-letter brand code (`PLN`, `WLD`, `PRM`, `GWT`, `SHM`, `PRP`, `GBN`, `PLT`, etc.).
* `[PRODUCT CODE]`: Canonical product or edition identifier (`PLA14`, `SVC001`, `SPRINT01`, `SHMCORE`, `HD01`).
* `[CHANNEL]`: Sales vector (`ETSY`, `PORTAL`, `UPWORK`, `FIVERR`, `TIKTOK`, `AMAZON`, `DIRECT`, `RETAINER`).
