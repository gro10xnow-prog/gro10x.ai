# WordPress

> Add your Chatbase AI agent to a WordPress website using the official Chatbase plugin and your Agent ID

## Overview

WordPress is the one website platform where you don't paste an embed script. Instead, you install the official Chatbase plugin and give it your Agent ID. The plugin handles the rest.

<Card title="What you can do:" icon="comments">
  Put your AI agent in front of every visitor to your WordPress site, with no theme code to edit.
</Card>

## Before you start

* A Chatbase account with an AI agent, and [the AI agent enabled](/docs/user-guides/quick-start/your-first-agent#navigate-to-the-channels-section). If you don't have an account, [create one for free](https://www.chatbase.co/auth/signup); if you're not sure how to build an AI agent, see [Your first AI agent](/docs/user-guides/quick-start/your-first-agent).
* A WordPress site where you can install plugins, and access to your admin dashboard.

## How to add your AI agent

<Steps>
  <Step title="Log in to your WordPress admin dashboard">
    Your dashboard URL is typically *yourdomainname.com/wp-admin/*. You can also reach it through your web hosting control panel.
  </Step>

  <Step title="Install and activate the Chatbase plugin">
    In the left sidebar of your WordPress admin dashboard, click **Plugins**.

    <Frame>
      <img src="https://mintcdn.com/chatbase/JnjROJ-aB2q57UGe/user-guides/integrations/images/wordpress/wordpress-1.webp?fit=max&auto=format&n=JnjROJ-aB2q57UGe&q=85&s=6049a461b8a99783b6b6d527a2e6ab71" alt="The Plugins item in the WordPress admin sidebar" width="1892" height="730" data-path="user-guides/integrations/images/wordpress/wordpress-1.webp" />
    </Frame>

    Click **Add New Plugin** at the top of the next page.

    <Frame>
      <img src="https://mintcdn.com/chatbase/JnjROJ-aB2q57UGe/user-guides/integrations/images/wordpress/wordpress-2.webp?fit=max&auto=format&n=JnjROJ-aB2q57UGe&q=85&s=8abec164b93bfaff6308ab52245348cd" alt="The Add New Plugin button in WordPress" width="1896" height="734" data-path="user-guides/integrations/images/wordpress/wordpress-2.webp" />
    </Frame>

    In the search bar, type **Chatbase**. Find the Chatbase WordPress plugin, click **Install Now**, then **Activate**.

    <Frame>
      <img src="https://mintcdn.com/chatbase/JnjROJ-aB2q57UGe/user-guides/integrations/images/wordpress/wordpress-3.webp?fit=max&auto=format&n=JnjROJ-aB2q57UGe&q=85&s=5c73c36d12ce8dfe9a040aefd006c63b" alt="Installing the Chatbase plugin from the WordPress plugin directory" width="1898" height="861" data-path="user-guides/integrations/images/wordpress/wordpress-3.webp" />
    </Frame>
  </Step>

  <Step title="Open the Chatbase plugin settings">
    1. In the left sidebar of the WordPress admin dashboard, click **Settings**.
    2. Look for **Chatbase options** and click it.
    3. Find the text box labeled **Agent ID**.

    <Frame>
      <img src="https://mintcdn.com/chatbase/JnjROJ-aB2q57UGe/user-guides/integrations/images/wordpress/wordpress-4.webp?fit=max&auto=format&n=JnjROJ-aB2q57UGe&q=85&s=3174da4eef42c8d45ea4eb2809413763" alt="The Agent ID field in the Chatbase WordPress plugin settings" width="1895" height="822" data-path="user-guides/integrations/images/wordpress/wordpress-4.webp" />
    </Frame>
  </Step>

  <Step title="Copy and paste your Agent ID">
    1. Go to your Chatbase [dashboard](https://www.chatbase.co/dashboard/) and select the AI agent you want to embed.
    2. Click **Settings** in the sidebar and stay on the **General** tab. Copy the **Agent ID** from the **Agent details** card.
    3. Paste the Agent ID into the text box in your WordPress settings.

    <Frame>
      <img src="https://mintcdn.com/chatbase/qI0LQ6QhbuUlH68f/user-guides/integrations/images/Integrations/Agent-ID.png?fit=max&auto=format&n=qI0LQ6QhbuUlH68f&q=85&s=6707c1fc504200328f83e77dfebfbfd0" alt="Locating the Agent ID in the Chatbase dashboard" width="2336" height="902" data-path="user-guides/integrations/images/Integrations/Agent-ID.png" />
    </Frame>
  </Step>

  <Step title="Save your changes">
    Click **Save Changes**.
  </Step>
</Steps>

<Check>
  Visit your WordPress site and confirm the Chatbase AI agent appears and responds.
</Check>

  <img src="https://mintcdn.com/chatbase/JnjROJ-aB2q57UGe/user-guides/integrations/images/wordpress/wordpress-6.webp?fit=max&auto=format&n=JnjROJ-aB2q57UGe&q=85&s=a60cc6a7d4f22d10645b9e04a828b10a" alt="The Chatbase AI agent live on a WordPress website" width="1549" height="482" data-path="user-guides/integrations/images/wordpress/wordpress-6.webp" />

<Note>
  You can customize the appearance and colors of your AI agent on your Chatbase dashboard. Go to your **dashboard**, choose an AI agent, click **Channels** in the left sidebar, click **Manage** on the **Chat bubble** card, then open the **Display** tab to edit Content, Capabilities, Colors, Floating bubble, and Localization.
</Note>
